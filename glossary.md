# Глоссарий
1. **Процессор (CPU)** — центральное устройство, выполняющее вычисления и управляющее работой ПК.
2. **Оперативная память (RAM)** — память компьютера, которая используется для временного хранения файлов, программ и операционной системы.
3. **Долговременная память** — устройства для постоянного хранения данных (SSD, HDD) после выключения ПК.
4. **Материнская плата** — основная плата, объединяющая и связывающая все компоненты компьютера.
5. **Видеокарта (GPU)** — устройство для обработки графики и вывода изображения на монитор.
6. **Блок питания** — устройство, преобразующее сетевое напряжение в необходимое для компонентов ПК.
7. **Шина** — канал передачи данных между различными устройствами компьютера.
8. **Периферийные устройства** — внешние устройства ввода/вывода (клавиатура, мышь, принтер).
